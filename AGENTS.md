# Finance Tracker agent instructions

Read and follow [the GitHub Development Standard](docs/github-development-standard.md) before implementation or Issue/Project updates. Its [Release / Version gate](docs/github-development-standard.md#release--version-gate) is required on every implementation/verification Issue handoff and final report, including documentation-only work. Resolve impact before Verify, report every gate field explicitly, and leave owner acceptance Pending until confirmed. Apply the canonical rules for Unreleased, grouped candidates and deferred release preparation; do not duplicate the policy here.

Use the existing Project item and workflow; preserve Priority and unrelated metadata. The owner performs Git commits. Preserve local work, and follow the standard's authorization boundaries for staging, pushes, tags, publication and production actions.
